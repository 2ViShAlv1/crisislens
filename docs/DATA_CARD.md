# Data card — CrisisLens

All numbers are from `eval/results/data_stats.json`, `class_support.csv`, `event_support.csv`, `sft_selection_support.csv` (generated by `src/data/prepare.py` / `select_train.py`).

## Source
- **HumAID** (Alam et al., *HumAID: Human-Annotated Disaster Incidents Data from Twitter with Deep Learning Benchmarks*, ICWSM 2021). 19 natural disasters, 2016–2019, English tweets, crowd-annotated humanitarian categories.
- Obtained from the Hugging Face mirror `QCRI/HumAID-all` (parquet: `tweet_text`, `class_label`). The CrisisNLP direct download returned HTTP 403 and the Harvard Dataverse file is access-restricted.
- **License: CC BY-NC-SA 4.0** → non-commercial; this repo ships **scripts only, no data dumps**. Derived models inherit the NC-SA terms.
- This release contains **10 classes** (`dont_know_cant_judge` is absent from the HF/"all" release; the paper's "All" benchmark also uses 10 labels).

## Recovering event ids
The HF mirror has no event column, but rows are stored event-by-event in the paper's canonical order. Two independent methods were used:
1. ordered dynamic-programming segmentation over event-keyword hits (`src/data/assign_events.py`);
2. slicing by the per-event split sizes in the paper's Table 6.

They agree on **99.99%** of rows (`dp_vs_paper_event_agreement` = 0.99988); (2) is used. One inconsistency in the paper was found: Hurricane Matthew dev/test sizes (329/168) are swapped relative to the data (168/329); the swapped values are the only ones consistent with split totals and keywords.

## Cleaning
| Step | Rows affected |
|---|---|
| Raw rows | 76,484 |
| Tweets with an `RT` prefix (prefix stripped) | 11,082 |
| URLs removed, `@handles` → `@user`, HTML unescaped | all |
| Dropped: < 3 tokens after cleaning | 3 |
| Exact duplicates (normalised text) | 3 |
| Near-duplicates within train / within test (TF-IDF 1–2-gram cosine ≥ 0.9) | 12 / 16 |
| Train rows removed as exact / near duplicates of a test row | 8 / 7 |
| Label conflicts on identical text | 0 |

HumAID was already de-duplicated by its authors, which is why so few rows are removed. Each row keeps a traceability id = `sha1(original tweet text)[:16]` (the mirror has no tweet ids).

## Splits — event-level holdout (no event appears in more than one side)
- **Test (21,527 posts): 4 unseen disasters** — Kerala floods 2018 (India, 7,982), Hurricane Dorian 2019 (7,599), Cyclone Idai 2019 (Mozambique/Zimbabwe/Malawi, 3,932), Mexico earthquake 2017 (2,014). Three non-US events; flood, cyclone, hurricane and earthquake types.
- **Train (49,417) / Val (5,491)**: the other 15 events; val is a 10% stratified (by class) split.
- **LLM eval subset (1,219)**: 300 random posts per test event (seed 42) + all 19 `missing_or_found_people` test posts, so every class has support. All LLM systems are scored on this identical subset; TF-IDF is reported on both the subset and the full test set.
- **SFT subset (17,786)**: from train, each class capped at 2,000 (random) and all posts of rarer classes kept (no duplication).

## Labels
- **`category` = human gold** (HumAID crowd labels). Known noise exists (e.g. product ads labelled as damage); we do not relabel.
- **`actionable`, `urgency`, `location`, `needs`, `rationale` = silver**, produced by a teacher LLM (`gemma-4-31b-it` via the Adaption Responses API, temperature 0). The teacher is given the gold category and fills the other fields consistently with it (`src/data/teacher_label.py`). 20 posts per request because of the platform's per-user rate limit; the first ~900 rows were labelled one post per request.
- **Verification**: 100 random silver labels (50 train-subset, 50 test-subset) were reviewed against the rubric by an independent reviewer. **The reviewer was Claude (an LLM), not a human** — a human-review sheet is provided at `eval/human_check/verify_sheet.csv`. Agreement: actionable 97%, urgency within ±1 100%, location 94%, needs 96%, all four fields 89%. Main teacher error mode: leaving `location` null when a place is written (5 of 6 location errors); one hallucinated location.

## Known limitations
English only; Twitter 2016–2019 register; US hurricanes dominate training (Harvey/Irma/Maria/Florence ≈ 58% of train); annotator noise in gold labels; silver extra fields inherit teacher bias (conservative on `actionable`).
